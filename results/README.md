# Results

The completed local Experiment 1 trace is kept in ignored `runs/`. The compact
binary correctness export
[experiment1-nine-model-correctness.csv](experiment1-nine-model-correctness.csv)
contains one named configuration per row and 200 search plus 200 audit
correctness columns. It contains only the final `0/1` workflow correctness
bits, not model responses or answer text. Recreate it with
[export_experiment1_correctness_csv.py](../scripts/export_experiment1_correctness_csv.py).

The matching realized proxy-cost matrix is
[experiment1-nine-model-cost-usd.csv](experiment1-nine-model-cost-usd.csv).
Each value is the complete row/question charge under the registered formula:
model coefficient times input tokens for every reached solver and verifier
call. Recreate it with
[export_experiment1_cost_csv.py](../scripts/export_experiment1_cost_csv.py).

The smoke demo uses invented outcomes to check implementation behavior only.

[diagnostics-2026-09-23.json](diagnostics-2026-09-23.json) contains nine exact calculations on invented populations, generated by [research_diagnostics.py](../scripts/research_diagnostics.py). Its provenance, assumptions, interpretation and reproduction command are in the [diagnostics note](../docs/research/deep-review/05-diagnostics-and-pilot.md). The script and artifact are committed together and checked for agreement in CI. These calculations are not LLM measurements or evidence of a method outperforming a baseline.

Put generated benchmark output in ignored `runs/`. A committed empirical result summary must identify its run record, commit, uncertainty, and limitations.
