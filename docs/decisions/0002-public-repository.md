# 0002: Public repository and enforced reviews

Date: 2026-09-23. Status: applied at the owner's explicit request.

The owner requested public visibility during setup. The repository is now public, superseding the private default in decision 0001. This also makes branch protection available on the current GitHub plan.

Protect `main` with one approving review, required passing `offline-checks`, an up-to-date branch, resolved review conversations, dismissal of stale approvals, linear history, and no force pushes or branch deletion. The owner retains administrator override for setup/recovery. Normal team changes use branches and reviewed pull requests.

Original screenshots, downloaded PDFs, caches, and raw data remain local as documented in the repository data conventions. Teammate invitations still require their actual usernames. The software license remains a separate group decision.
